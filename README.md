# Regicide — نسخه دیجیتال

> **وضعیت پروژه:** Closed Beta — در مرحله‌ی نهایی توسعه و پولیش

پیاده‌سازی دیجیتال بازی رومیزی **Regicide** با استفاده از Unity و C#.

هسته‌ی اصلی گیم‌پلی و قوانین بازی تکمیل شده و نسخه‌ی فعلی قابل اجرا است. توسعه‌ی فعلی بر رفع باگ‌های باقی‌مانده، بهبود انیمیشن‌ها، رابط کاربری و سیستم صوتی متمرکز است.

## وضعیت توسعه

* **گیم‌پلی و منطق بازی:** تکمیل‌شده
* **رابط کاربری:** تکمیل‌شده
* **رفع باگ‌ها:** در حال انجام
* **انیمیشن‌ها:** در حال بهینه‌سازی
* **افکت‌های صوتی:** در حال توسعه
* **موسیقی متن:** در انتظار پیاده‌سازی

## فناوری‌ها

* Unity 6.4 (6000.4.8f1)
* C#
* DOTween

## اجرای پروژه

پروژه را در **Unity 2022.3 LTS** باز کرده و صحنه‌ی زیر را اجرا کنید:

```text
GameScene
```
